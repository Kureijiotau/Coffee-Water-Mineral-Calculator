name: Concentrate mass workflow
description: Owner-required mass basis and preparation sequence for all concentrate tools and explanations.
---

The user requires fully weight-based concentrate workflows throughout the app, including guides: add 20–30% of the calculated base water, add salts, shake/mix, then add the rest to target. Explain that plain water's mL and grams are approximately interchangeable; do not apply that approximation to finished concentrate.

**Why:** The user finds volume measurements confusing and wants w/w as the basis of concentrate preparation everywhere. They explicitly selected fully weight-based concentrates rather than preparation-copy changes only.

**How to apply:** Audit calculations, preparation instructions, dosing, and saved-stock handling together. Keep old volume-based stocks explicitly identified rather than silently reinterpreting them as mass-based. This is the approved direction; check current code for implementation status.
