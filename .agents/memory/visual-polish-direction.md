---
name: Visual polish direction
description: The calculator's approved visual language for future UI polish passes
---

Keep the existing cyan, emerald, indigo, and violet palette, but use it dramatically: layered dark instrument-console surfaces, stronger active-state glow, inset borders, and deliberate depth.

**Why:** The user explicitly chose to keep the current palette and asked for a more dramatic, premium visual treatment rather than a new visual identity.

**How to apply:** Prefer visual-only refinements to shared surfaces, hierarchy, focus states, and active controls before introducing new colors, layouts, or component patterns.
