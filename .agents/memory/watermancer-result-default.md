---
name: Watermancer result card default
description: Automatic match results remain in normal document flow by default, with viewport following available as an explicit toggle.
---

The Watermancer automatic-match result card defaults to staying in place in the page layout. Users can explicitly enable viewport-following with the card’s Follow screen button; mode switches and full resets restore the in-place default.

**Why:** The reference behavior keeps the result card from covering the builder and avoids making the page feel constrained by a permanently floating panel.

**How to apply:** Keep the default sticky/follow state off unless the user explicitly requests persistent viewport anchoring.
