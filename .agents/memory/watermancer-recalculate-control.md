---
name: Watermancer recalculation control
description: Advanced matching changes can be explicitly applied through a full primary-plan recalculation.
---

Watermancer exposes a Recalculate match action after advanced controls so users can deliberately apply the complete matching strategy to the current target, visible waters, salts, hydration forms, priority, and overshoot policy.

**Why:** The guided workflow contains many coupled settings, and users need a clear confirmation point when they have finished tuning them rather than wondering whether the displayed dose reflects every change.

**How to apply:** Invalidate the full primary solver result from the button, then derive dosing, ion coverage, and final-mixture review from that refreshed primary result. Preserve the edited controls and manual additions.
