Use the product label as the dosing basis: one 1.8 g scoop contains 210 mg elemental magnesium, leaving 1.59 g of label-derived glycinate carrier mass.

**Why:** The supplement’s labeled elemental-magnesium fraction does not match the theoretical fraction of pure anhydrous magnesium bisglycinate, so using only a textbook formula would misstate the actual product dose.

**How to apply:** Keep elemental magnesium in the normal core-ion path so all salt, water, matching, and concentrate calculations work normally. Keep the remaining carrier as a supplemental display-only component; do not invent chloride, sulfate, bicarbonate, or a new Watermancer target dimension.
