---
name: Standalone concentrate workspace
description: Concentrate creation is an independent one-stock-at-a-time app workspace.
---

Concentrate creation lives in its own app-header tab, separate from Brewer, Alchemist, and Watermancer. The first workflow is standalone: choose one salt and hydration form, set any strength from 1% upward and a bottle volume, then prepare, calibrate, and preview final-water dosing.

**Why:** The user wants concentrate tools consolidated without adding more clutter to the recipe workflows, and their physical setup uses separate small dropper bottles.

**How to apply:** Keep this tab focused on one stock at a time. Reuse the shared salt definitions, hydration forms, solubility warnings, and saved dropper calibration. Keep salt-per-mL, salt-per-drop, and final-water contribution derived from the selected stock rather than introducing a second chemistry model.
