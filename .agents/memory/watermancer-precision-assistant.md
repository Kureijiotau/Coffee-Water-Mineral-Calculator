name: Watermancer precision assistant
description: Watermancer should guide precision preparation without adding another workflow step.
---

The precision assistant is Watermancer-first and progressive: recommend a larger dry-salt batch first, then a concentrate, then dropper dosing. Use a conservative built-in 100 mg minimum dry dose rather than adding scale settings in the initial version.

**Why:** The user wants better precision without further clutter or workflow disruption; 0.001 g scales can still be unreliable for 1–20 mg doses.

**How to apply:** Keep the assistant attached to the batch-volume card, derive it from the active target/water/salt plan, and require explicit user action before changing the final volume or preparation method. Extend to Alchemist later only if the same interaction remains clear.
